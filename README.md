# Portafolio LAKY

Portafolio personal de LAKY, creado como sitio estático responsive.

## Incluye
- Presentación personal y áreas de trabajo.
- Proyectos: NEXORA Weapons, HyperMC Oficial, Velnora Hotel Empire y VELNORA Studios.
- Desarrollo web, gaming, moderación y gestión de comunidades.
- Animaciones al desplazarse, fondos visuales, galería multimedia preparada y diseño adaptable.

## Publicar con GitHub Pages
1. Abre **Settings → Pages**.
2. En **Build and deployment**, elige **Deploy from a branch**.
3. Selecciona **main** y **/(root)** y guarda.

## Para completar
Sustituye las imágenes de muestra por capturas propias, añade enlaces a demos y repositorios, y agrega un medio de contacto. Las descripciones presentan proyectos e iniciativas; añade métricas o experiencia laboral verificable solo cuando corresponda.

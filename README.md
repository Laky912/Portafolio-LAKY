# Portafolio LAKY

Portafolio personal de LAKY, desarrollado como sitio estático responsive.

## Secciones
- Presentación y perfil personal.
- Mi historia: recorrido de aproximadamente dos años aprendiendo y creando proyectos.
- Servicios y especialidades: desarrollo Minecraft, desarrollo de bots y comunidades Discord, desarrollo web, moderación, administración y apoyo como developer.
- Habilidades y proyectos: NEXORA Weapons, HyperMC Oficial, Velnora Hotel Empire y VELNORA Studios.
- Trayectoria práctica, galería preparada para demos y contacto.

## Diseño
- Estética oscura tecnológica con acentos cian.
- Diseño adaptable a escritorio, tablet y móvil.
- Animaciones de entrada al desplazarse, efectos hover y movimiento sutil 3D en tarjetas.
- Respeta la preferencia del navegador por reducir movimiento.

## Disponibilidad
El portafolio aclara que LAKY no está disponible actualmente para incorporarse de inmediato a un puesto fijo o cargo continuo, pero está abierto a conversar propuestas y valorar colaboraciones puntuales.

## Publicar con GitHub Pages
1. Abre **Settings → Pages**.
2. En **Build and deployment**, elige **Deploy from a branch**.
3. Selecciona **main** y **/(root)** y guarda.

## Para completar
Sustituye las imágenes de muestra por capturas propias, añade enlaces a demos y repositorios y agrega un medio de contacto directo. Las descripciones presentan experiencia práctica y proyectos; añade cargos, fechas o métricas verificables solo cuando correspondan.
